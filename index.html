decoroom — instructions for AI agents

This is the static HTML of decoroom, an app for sketching a room's furniture layout. If you were given a decoroom link, the room is stored entirely in the link's fragment (the part after #). Browsers and fetch tools never send the fragment to the server, so this page can't show you the room. Read it from the link itself, as described here.

Fastest way: the command-line tool (Node 18+, nothing to install)

curl -sO https://njvack.github.io/decoroom/decoroom.mjs
node decoroom.mjs describe 'LINK'               # text summary: walls, doors, every piece, distances, open floor
node decoroom.mjs render 'LINK' -o plan.png     # top-down picture to look at (or .svg)
node decoroom.mjs render 'LINK' -o wall.png --view wall:2    # straight-on view of wall 2 (index or name)
node decoroom.mjs decode 'LINK' > room.json     # readable JSON you can edit
node decoroom.mjs encode room.json              # prints a new link (keeps the room id from room.json)
node decoroom.mjs diff 'OLD_LINK' 'NEW_LINK'    # what changed

Put the link in single quotes; it contains &. LINK can also be a file holding the link, or - for stdin.

Link format

  • https://njvack.github.io/decoroom/#id=ROOMID&z=DATA — DATA is base64url (no padding) of raw DEFLATE (no zlib header) of a JSON array in a compact positional form. Python: json.loads(zlib.decompress(base64.urlsafe_b64decode(z + '=' * (-len(z) % 4)), -15)). The positional field order is in llms.txt; using decode above is easier.
  • …/#id=ROOMID&j=JSON — the same room as readable JSON, URI-encoded (encodeURIComponent). Write links in this form if you can't run the CLI; the app accepts it and shortens it.
  • id identifies the room in each person's local history. When you edit someone's room, keep their id so they see a "what changed" summary when they open your link.

Readable JSON (the j= form and the CLI's decode output)

Lengths are inches. x grows to the right, y grows down. Omit anything you don't need.

{
  "name": "Living room", "units": "in", "ceiling": 96,
  "verts": [[0,0],[144,0],[144,180],[0,180]],          // room corners, any polygon
  "walls": [                                              // walls[i] runs verts[i] → verts[i+1]
    {"name": "Window wall", "paint": {"color": "a9b59b"},
     "features": [{"kind": "window", "at": 30, "w": 48, "y": 30, "h": 50}]},
    {"name": "Hall side", "features": [{"kind": "door", "at": 12, "w": 32, "hinge": "end"}]},
    {"name": "Kitchen side", "features": [{"kind": "opening", "at": 50, "w": 40, "label": "Kitchen", "est": true}]},
    {"name": "Fireplace wall", "features": [{"kind": "fireplace", "at": 60, "w": 56, "depth": 16},
                                            {"kind": "art", "at": 70, "w": 36, "h": 24, "y": 56, "paint": {"sketch": 0}}]}
  ],
  "floor": {"color": "d8c7a8", "pattern": "wood"},
  "items": [
    {"id": "sofa", "name": "Sofa", "type": "seat", "w": 84, "d": 36, "x": 72, "y": 20, "rot": 0,
     "anchors": [{"wall": 0, "edge": "near", "dist": 2}], "paint": {"color": "c2683f"}},
    {"id": "rug1", "type": "rug", "w": 96, "d": 72, "x": 72, "y": 70, "paint": {"color": "e9e2d3", "pattern": "diamond", "color2": "a8432d"}, "est": true}
  ],
  "sketches": [{"w": 12, "h": 8, "pal": ["e9e2d3", "c2683f"], "paths": [[0, "M0 0h12v8H0z"], [1, "M3 2h6v4H3z"]]}],
  "notes": "Free text."
}
  • Features sit on a wall, at inches from the wall's start corner, w wide. Kinds: door (hinge start|end, swing in|out), opening, slider, window (y sill height, h), fireplace (depth = hearth depth), art (y bottom, h, paint).
  • Items: type is box|seat|table|storage|bed|rug|lamp|plant; shape rect|round|L. w is along the piece's back, d front to back, h height. x,y is the center. rot is degrees clockwise; at 0 the back faces −y (the top of the plan).
  • Anchors (up to 2 per item) pin a piece to walls: "this edge is dist inches from wall wall". edge is near (closest edge, default), center, or far. Anchors win over x/y.
  • Paint: {"color": "hex", "pattern": "stripe|check|plaid|herringbone|wood|dots|grid|tile|brick|diamond|chevron|terrazzo|shag|boucle|floral", "color2": "hex", "scale": 1, "angle": 0}, or {"sketch": index} to use a sketch.
  • Sketches are tiny SVG drawings carried in the link: w×h viewBox, a palette of hex colors, and [paletteIndex, pathData] pairs. Use integer coordinates and keep each under ~1,500 characters so links stay short.
  • est: true marks a guess (drawn dashed and listed for the person to measure). Mark anything you estimated from photos this way.

Full reference: llms.txt. Source: github.com/njvack/decoroom.
